# 👋 Soy Diego — DevOps · Cloud · SRE

Automatización, infraestructura como código y observabilidad. Trabajo con **Docker, Kubernetes (K3s) y Ansible**, despliego en la nube (**AWS / Azure**) y construyo la capa de **métricas, logs y alertas** que mantiene las plataformas de pie.

- **DevOps:** Docker, Kubernetes (K3s), Ansible, CI/CD (GitHub Actions), GitOps / IaC
- **Cloud:** AWS (EC2, S3, Lambda, SAM) · Azure (en formación)
- **SRE / Observabilidad:** VictoriaMetrics (PromQL), Grafana, Loki, alertas y dashboards versionados
